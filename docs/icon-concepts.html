Valheim: Deep Waters

Icon Concepts

Inventory icon mock-ups for every rod, hook, bait and buff item, drawn on Valheim-style slots. Each card shows the file name the mod looks for, so a finished icon can be dropped straight into the Models folder.

Style guide

Canvas

128×128 PNG with a transparent background. Fill about 80% of the square; long items (rods) run corner to corner.

Angle and light

Three-quarter view, light from the top left, a soft dark edge so the shape reads on the dark slot. Matches vanilla's painted look.

Read at a glance

Tiers share a shape and change material and colour. Hooks carry their size label; meads show their tier by bottle size, like vanilla meads.

File names

<model>_icon.png in BepInEx/config/ValheimDeepWaters/Models, or a sprite of that name in any bundle there.
