Valheim: Deep Waters

Rod Concepts

Side-view sketches for the eight rod tiers, one per era. Each one is built from the same materials as its recipe, so the rod reads as part of that biome at a glance. Drawn to scale for a 2.2 m rod, butt on the left.

Modelling spec for every rod

Size

About 2.2 m long. Grip 40–45 cm with the reel seat 30 cm up from the butt. Shaft about 3.5 cm thick at the grip, 0.6 cm at the tip.

Pivot and axes

Put the origin where the hand holds the grip. The mod finds the tip as the far end of the longest axis, so the tip must be the end farthest from the origin. The line attaches there automatically.

Budget

1,500–4,000 triangles. One 1024 px texture (512 is plenty for the wood tiers). The guides and reel carry the detail; the shaft can stay simple.

Export

Export in metres with Y up, and tick Read/Write on the import settings so the mod can size it. Name each prefab rod_wood, rod_copper, and so on; they can all live in one rods.bundle.
